# Kcal

Osobní kalorický deník Prokopa Dudmana na každý den: deník jídel, makra, mikronutrienty, zásoby a sken čárového kódu.

Čisté HTML, CSS a JavaScript, bez buildu a bez serveru. Zápisy, vybraný den a vlastní potraviny zůstávají v prohlížeči (localStorage). Hledání a čárový kód umí sáhnout do Open Food Facts — ven jde jen text dotazu nebo číslo kódu. Dá se přidat na plochu iPhonu.

Náhled: https://prokopdud.github.io/kcal-app/
